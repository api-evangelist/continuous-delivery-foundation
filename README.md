# Continuous Delivery Foundation (continuous-delivery-foundation)
The Continuous Delivery Foundation (CDF) is a Linux Foundation project supporting open source projects for continuous delivery and DevOps practices. It hosts Jenkins, Tekton, Spinnaker, and related tools that enable organizations to build, test, and deploy software faster and more reliably.
